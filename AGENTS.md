# Development guidance

- Follow `D:/code/guide.md` for shared AI project layout. This file supplies repository-specific contracts.
- Data presets belong in `config/data/`; training presets belong in `config/train/low_res.yaml` and `config/train/sr.yaml`. Use `model`, `augmentation`, `conditioning`, `loss`, `optim`, `lr_bank`, and `train` only where needed. Keep data paths, phase counts and resolution in data presets; keep batches, augmentation and optimization in training presets.
- Use descriptive configuration keys, `[]` lists, blank lines between related groups and brief comments for ambiguous units or semantics. Resolve selected data files with `src/config.load_train_config`; save the effective, embedded data settings with the run. Legacy names are migrated at configuration/model assembly boundaries. New SR settings select their own data and bank guidance, and validate their contract against the frozen LR model.
- Keep training presets focused on experiment choices. Omitted advanced options resolve from `TRAIN_DEFAULTS`/`STAGE_DEFAULTS` in `src/config.py`, after legacy migration; explicit values always win. Omitted `optim.critic_lr` follows `generator_lr`. Save resolved values so changing defaults cannot alter saved runs. Do not derive independent loss weights, batch counts or physical augmentation assumptions merely because their current values match.
- `src/model/`: neural networks and diffusion math; `src/data/`: datasets and augmentation; `src/prepare/`: shared phase conversion and resizing.
- `src/train/`: stage-1 and SR training, losses, EMA and training state; `src/predict/`: generation, extension and super-resolution inference.
- `src/build/`: assembly; `src/serve/`: HTTP; `src/evaluate/`: measurements; `src/simul/`: simulation; `src/storage.py`: tensor artifact I/O.
- Preserve the public `from src.api import InferenceAPI, PlaneAnchor, create_app` interface and legacy stage-1 state dictionaries. Internal imports use their owner modules.
- Keep `src/build/model.py` limited to network construction and `src/build/predict.py` to inference assembly. Public inference imports must not load `src/train/`. Training step logic belongs in `train/trainer.py` or `train/sr.py`; run scheduling and artifacts belong in `train/run.py` or `train/sr_run.py`.
- `data.crop_size` is the original 2D field of view in pixels and `data.lo_res_size` is the LR grid size. SR alone owns `model.generator.scale_factor`; `hi_res_size = lo_res_size * scale_factor`. Fractional scale factors are allowed when the result is integral. Do not equate crop size with HR size.
- New LR preprocessing is original crop → LR; SR real slices are original crop → HR. Share phase conversion/resizing through `src/prepare/resize.py`. Preserve original crop → HR → LR for legacy LR run configs containing `data.scale_factor`, and nearest-exact for legacy `input_size` configs. Migrate legacy SR `data.scale_factor` to its model setting when loading. SR source compatibility compares crop/LR sizes, phases and domains, not the SR output size.
- Train SR from frozen generated LR volumes and real HR 2D slices. Generated LR volumes are conditions, not measured 3D ground truth.
- Keep categorical phase IDs and axis meanings explicit. Resize phase channels rather than averaging numeric IDs.
- Name planes `xy`, `xz`, `yz`. Volumes retain D,H,W = z,y,x; their normal axes are 0, 1, 2 respectively. Raw row/column directions are y/x, z/x, z/y. `src/plane.py` owns these mappings. Read legacy numeric config/critic names at load boundaries; retain the numeric anchor API.
- `model.critic.plane_groups` partitions observed planes into shared critics, one model and optimizer per group. Use canonical names such as `xy` and `xz_yz`; absence means legacy independent critics. Average member-plane losses within groups. LR stability version 2 and SR also average groups; legacy LR version 1 sums them. SR keeps groups separate per domain. Preserve v1/v2 SR resume through optimizer-state migration; v3 saves per-critic optimizers. Do not change group membership on resume or silently merge independent weights.
- Keep augmentation policies per plane, independently of critic sharing. `augmentation.planes` uses physical `flip_axes` and `rotate_90`; `data.thickness_axis` forbids reversing or exchanging the thickness direction. Preserve alignment within diffusion-time pairs, connectivity triplets and associated channels; real/fake samples follow the same plane policy. Input orientation must already match the plane convention. Thickness-axis protection does not implement absolute crop-position conditioning.
- LR stability version 2 counts actual critic updates for regularization and preserves connectivity-triplet order along the thickness normal. Preserve version-1 behavior for saved configs. Time embedding defaults to index; optional scaled embedding uses 1000*t/num_steps consistently in the generator, critic and inference. R2 defaults off and shares the R1 cadence; SR keeps WGAN-GP.
- `src/train/step.py` owns finite-loss/gradient checks and optimizer-step diagnostics. Update LR's shared scaler once per iteration, and update EMA only after a successful generator step. `src/train/state.py` owns LR training checkpoints and source hashes; inference weight formats remain unchanged. LR and SR training must not set fixed seeds or persist/restore RNG state or data order. Keep seed-based reproducibility in prediction only. Preserve same-step shared noise for aligned reference pairs. Record resolved configuration and diagnostic metrics with each experiment.
- Use the project `.venv`. Run focused tests first, then `python -m pytest tests -q`; use the configured formatter and Ruff checks.
- Preserve unrelated working-tree changes. Training runs, cached LR banks and generated outputs belong in `run/` and are not committed.
- Keep recorded paper results separate from new experiments; a smoke test does not establish reconstruction quality.
